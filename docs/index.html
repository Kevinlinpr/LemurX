01

反爬虫机制

不注入脚本，不挂 DevTools。文字来自一次无障碍树快照，点击是真的触摸事件。反自动化站点面对的是一只真实的手，不是爬虫。

02

长任务调度

盯站点、做计划、连续操作，都可以作为长任务跑下去。浏览器退到后台时，任务可以接着跑；回到前台，你仍然接得住。

03

Agent 捆绑标签页

一个标签绑一个 Agent。它读过的页、点过的按钮、交过的任务，都留在这个标签里，不和别的标签串台。

04

Agent 对话

浏览器的主界面就是对话。原生聊天、流式回答；需要上网时，Agent 在同一个标签里打开真网页，你看得见每一步。
